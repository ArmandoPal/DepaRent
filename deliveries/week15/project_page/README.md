# Página del proyecto

_Pendiente._ La guía pide una página con: **descripción del producto, integrantes, imagen representativa,
instrucciones de ejecución y enlaces relevantes**. El video demo ya no se pide (indicación del profesor, 17-nov).

Propuesta: una página estática (`index.html`) publicada con GitHub Pages desde `main`, con estos bloques:

1. Nombre, frase de valor y botón a la app (https://deparent.onrender.com).
2. Imagen representativa (captura de `week10/screenshots/01_inicio.png` u `08_detalle_resumen.png`).
3. Qué hace: propietario e inquilino, con 3–4 capturas.
4. Cómo funciona: diagrama de `../architecture/system_architecture.png` y cifras de evaluación.
5. Equipo y roles.
6. Enlaces: repositorio, informe final (PDF), presentación (PDF), instrucciones de ejecución.

Para publicarla: Settings → Pages → Source: rama `main`, carpeta `/docs` (mover ahí el `index.html`), o usar la
ruta `deliveries/week15/project_page/` con un workflow de Pages. Lo decide quien administra el repositorio.
