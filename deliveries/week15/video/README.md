# Video demo

**Enlace:** _pendiente_ (YouTube, "no listado")

Requisitos de la guía: **5 a 7 minutos**, presenta el proyecto y demuestra el producto final. Debe explicar el
problema, los usuarios, los datos, las funciones principales, el enfoque analítico, los resultados de evaluación
y las limitaciones. El enlace va en el informe final, en la página del proyecto y en el README raíz.

## Guion sugerido (≈ 6 min)
| Tiempo | Contenido | Pantalla |
|---|---|---|
| 0:00–0:40 | Problema: un propietario no sabe a cuánto alquilar; los portales no comparan | Inicio |
| 0:40–1:10 | Usuarios: propietarios (principal) e inquilinos (secundario) | Inicio |
| 1:10–1:50 | Datos: 3,128 anuncios de septiembre, capturas diarias, BCRP, ATU | Diagrama de arquitectura |
| 1:50–3:30 | Demo del propietario: caso de Jesús María (estimado, comparables, escenarios, simulador) | Probar / Agregar departamento |
| 3:30–4:30 | Demo del inquilino: búsqueda con filtros y "por debajo del estimado" | Buscar / ficha |
| 4:30–5:30 | Resultados: MAE S/ 553 contra S/ 993 del baseline; validación de noviembre; error por rango | Tablas de evaluación |
| 5:30–6:15 | Limitaciones y trabajo futuro | — |

## Antes de grabar
- Abrir la app 5 minutos antes (Render tarda en despertar).
- Usar una cuenta de prueba (`demo@ejemplo.com`), nunca datos reales.
- Guardar una copia descargada del video para la presentación.
